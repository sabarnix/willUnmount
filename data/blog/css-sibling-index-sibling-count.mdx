`sibling-index() and sibling-count()` is now widely available after firefox added support on August 2026.

As the name suggests [`sibling-index()`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/sibling-index) is a function which returns the index of an element in DOM relative to it's sibling and [`sibling-count()`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/sibling-count) returns number of sibling DOM elements.

I was trying to see what use cases can achieved with these function for which we needed help of javascript earlier.
